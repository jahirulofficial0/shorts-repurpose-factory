# Shorts Repurpose Factory

Turn one long video or transcript into a hook-ranked Shorts plan — which clips to cut, opening lines, captions, titles, and a 7-day posting calendar.

## When to use
Use when the user provides a long video transcript (ideally with timestamps), a video summary, or a long-form script and wants Shorts / Reels / TikTok clips, hooks, captions or a posting schedule from it.

## Inputs to collect
- Transcript with timestamps (best) or without
- Niche and target audience
- Platforms (YouTube Shorts, Reels, TikTok)
- Posts per day (default 1)

If something essential is missing, ask for it in one short message (max 3 questions). If it is not essential, state your assumption and continue.

## Workflow
1. **Map the source** — list every self-contained moment: a claim, a story, a surprising number, a how-to step, a strong opinion, a before/after.
2. **Score each moment** 1–10 on: Hook (first 2 seconds stop the scroll), Standalone (makes sense with no context), Payoff (clear ending), Emotion/Novelty. Total out of 40.
3. **Select** the top 7–10 clips, 20–55 seconds each. Prefer clips that start mid-action; cut the warm-up.
4. **Write the opening line** for each — a rewritten first sentence or on-screen text that creates curiosity in under 12 words. Give 2 variants.
5. **Package** — on-screen caption, title (under 60 chars), description with 3–5 hashtags, and a loop/CTA idea.
6. **Calendar** — spread the strongest clips across 7 days, best clip on day 1, alternate topics so consecutive days are not repetitive.

## Rules
- Only use timestamps that exist in the input. If there are no timestamps, quote the start and end sentence instead.
- Never invent claims the speaker did not make.
- Flag clips that need context to make sense and explain the fix (on-screen text, B-roll).
- Be specific and actionable; no filler.
- Separate what is verified from what is assumed.

Always answer in exactly this structure:
